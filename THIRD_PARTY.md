# Source attribution

The collection adapts statements from Mathlib v4.24.0, commit f897ebcf72cd16f89ab4577d0c826cd14afaafc7. Source declaration names, source file paths, exact revision URLs, and short source excerpts are recorded in `corpus/catalog.json`. Mathlib is distributed under the Apache License 2.0. Original file author headers are preserved in the local Mathlib checkout; the source links identify their files. A copy of the upstream license is included as `licenses/mathlib-LICENSE`.

`Continuous.add` is generated by Mathlib's `to_additive` machinery from `Continuous.mul`; its source location points to that generating declaration and attribute.

The Stewart example is adapted from G. W. Stewart, Matrix Algorithms, Volume II: Eigensystems (2001), Chapter 1, Theorem 1.10, page 9, eigenvector part. The book PDF is not copied into this repository.

CLR is used as a topical guide to undergraduate algorithms. No claim is made that the selected Mathlib declarations reproduce numbered CLR theorems, and no CLR text has been copied.

For scholarly use of Mathlib, see https://leanprover-community.github.io/cite.html.
